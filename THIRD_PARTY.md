# Third‑party assets

This project bundles the following third‑party assets. Their licenses permit redistribution.

## Fonts
- **Bebas Neue** — SIL Open Font License 1.1
  <https://fonts.google.com/specimen/Bebas+Neue>
  (`cosmoduck-clock.widget/fonts/BebasNeue-Regular.ttf`, and copies in disk/weather)
- **Abel** — SIL Open Font License 1.1
  <https://fonts.google.com/specimen/Abel>
  (`fonts/Abel-Regular.ttf` in disk/weather/net/proc/hw)
- **Feather** icon font — MIT License
  <https://github.com/AT-UI/feather-font>
  (`fonts/feather.ttf` in weather/net) — weather and Wi‑Fi glyphs

## Original theme
- **Regulus Dark** (part of the Leonis Conky themes pack) by **Closebox73**, distributed under
  the GNU GPL v3. The Cosmoduck recolor, panel/ring artwork (`icons.png`, derived from the
  theme's `Box1.png`), the ring layout and the weather/icon scripts originate from that theme.

## Runtime dependency (not bundled)
- **macmon** by vladkens — MIT. Installed separately via `brew install macmon`; used by the
  Hardware Monitor widget to read Apple‑Silicon sensors without `sudo`.
